# MakeMyTrip airfare database

This folder is the provider-specific historical store for rendered MakeMyTrip flight results. It is intentionally separate from the root `database/` folder used by the Via/APIx pipeline.

Each scraper run writes date-stamped JSON snapshots, replacing only the same India-calendar date so reruns remain idempotent.

| Folder | Contents |
|---|---|
| `raw_scraped_flights/` | One row per visible MakeMyTrip flight card, including route, booking window, carrier, travel date, times, price, and `source_site: makemytrip.com`. |
| `route_window_summary/` | One row per route and booking window with the mean observed card price and sample size. |
| `manifest.json` | Date and row counts for the latest MakeMyTrip snapshot. |

The MakeMyTrip scraper does not write to the root Via/APIx database and does not participate in the Via GitHub Actions workflow. Its output is generated by `makemytrip/scraping/makemytrip_scraper_multiplecities.py`.
